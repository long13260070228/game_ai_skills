# 历史 Bug 适用性清单

来源为用户提供的《技术-客户端-H5-Bug同步列表》。下表是归一化的历史问题池，不代表每项适用于每个游戏，也不代表文档标注“已修复”的项目在当前提交仍然正确。参考提交、截图和旧补丁只能作为查找线索。

执行迁移时按目标平台、玩法和代码路径筛选，记录“通过／不通过／不适用／未验证”及证据。确认源基线已修复则继承，不重复修改。只读模式下仅报告，不应用补丁。

## 通用或跨玩法问题

| 历史问题 | 核验方向 |
|---|---|
| 屏幕朝向随窗口分辨率错误旋转 | 设计方向、模板引擎文件及运行适配一致性 |
| Loading 图片加载慢 | 闪屏图格式、尺寸与已有压缩配置；不在此运行压缩 |
| 调试加金币造成卡住 | 是否使用现行 NetworkManager，请求锁和加载层是否收尾 |
| 切换语言 UI 闪烁 | 资源加载与替换顺序 |
| 多语言图片 meta 尺寸不符 | 元数据与图片实际尺寸 |
| 二次打开界面多语言图片丢失 | 释放后的 SpriteFrame 有效性及重新加载 |
| 默认语言及 lang 参数不统一 | 支持集合、目标语言映射和默认回退 |
| 前后台切换后在后台重连 | 重连延迟回调执行时的后台状态 |
| 前后台音效停止/恢复异常 | 音频状态、异步播放及前台恢复 |
| 金币前端计算与后端不一致 | 资产数据来源及显示同步 |
| VConsole 开启后卡住 | 高频/超大日志，尤其 Loading 日志 |
| Loading 延迟且不能屏蔽操作 | 屏蔽层及时生效，动画延迟与节点命名 |
| 远程头像加载成功却不可见 | 图片类型和纹理识别 |
| 冗余资源和包体过大 | 有效引用、无用资源和现有排除配置；不扩展为全仓资源清理 |
| 图片失真 | 预乘与图集设置是否适用于实际资源 |
| 停服重复弹窗 | 已有退出提示与节点状态判断 |
| 游戏间声音开关互相影响 | LocalStorage 键是否按游戏区分 |
| Launch 重复添加 DebugNode | 异步加载完成后的挂载唯一性 |
| 闪屏与游戏页尺寸不同 | 模板与场景适配一致性 |
| 本地环境固定错误地址 | 网关与 HTTP 域名的实际环境配置 |
| 服务端控制埋点量 | dotOption 等目标协议支持时，核对过滤与初始化 |
| startup 传参不兼容服务器升级 | query 传递及平台字段保持完整 |
| 离开协议 leaveType/code 变化 | 以目标服务端协议核对退出类型和特殊值 |
| 保底提示未多语言化 | 适用时检查 update_esc_tip 及资源 |
| 公共库改名或废弃 API | 依赖版本、实际导出和有效调用 |
| 同平台资产图标尺寸不一致 | 平台资源规范与游戏 UI |

| 历史问题 | 原文适用范围／核验方向 |
